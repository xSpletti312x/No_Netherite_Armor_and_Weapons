# No Netherite Armor and Weapons

В этом репозитории представлены ограничения на создание незеритовых предметов с DiamondSMP: отдельные датапаки для разных версий, моды для разных загрузчиков и серверный плагин, совместимый с Bukkit.

## Какие рецепты отключены

Датапаки и плагин отключают кузнечные рецепты незеритовой брони, топоров, мечей и незеритового копья в тех версиях, где оно есть. Незеритовые кирки, лопаты и мотыги по-прежнему можно создавать.

## Датапаки

Датапаки для отдельных версий находятся в [Datapacks](Datapacks). В каждой папке версии есть файлы датапака и ZIP-архив для соответствующего диапазона версий. Выберите архив для своей версии Minecraft и поместите его в папку datapacks мира. Затем выполните /reload или перезапустите сервер.

Датапаки доступны для Minecraft от версии 1.16 до 26.3. В каждой папке есть собственный файл pack.mcmeta и подходящая структура каталогов рецептов.

## Моды

JAR-файлы модов для отдельных версий находятся в [Mods](Mods). В каждой папке версии есть JAR для соответствующего диапазона и распакованное содержимое архива. Выберите папку для своей версии Minecraft и поместите JAR в каталог mods нужного загрузчика. Эти JAR упаковывают датапаки в виде модов; указанные загрузчики и версии игры можно посмотреть в метаданных каждого JAR.

## Серверный плагин

Исходный код плагина находится в [Plugin](Plugin). Он рассчитан на Bukkit API и заявляет поддержку Folia. Одна сборка предназначена для серверов Bukkit, Spigot, Paper и Folia. Плагин скомпилирован с Spigot API 1.16.5 в байткод Java 8.

## Статус тестирования

Версии модов не тестировались. Плагин проверялся только на Folia 26.3; совместимость с другим серверным ПО и версиями Minecraft не подтверждена.

### Сборка

Установите JDK и Maven, затем выполните эту команду из каталога Plugin:

~~~powershell
mvn package
~~~

JAR плагина будет создан в Plugin/target/No_Netherite_Armor_And_Weapons-1.0.0.jar. Скопируйте его в каталог plugins сервера и перезапустите сервер.

Для применения этого правила используйте датапак или плагин; устанавливать оба одновременно не нужно.
